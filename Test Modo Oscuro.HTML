¿Qué protege la firma en modo oscuro?

  • Triple blindaje de fondo blanco: bgcolor="#ffffff" (HTML) + background-color: #ffffff (CSS) + background-image: linear-gradient(#ffffff, #ffffff) (anti-inversión)
  • Caja gris protegida: Mismo triple blindaje con #eaebed
  • Colores de texto fijados: <font color=""> para Outlook + CSS inline + !important para Gmail
  • Imágenes PNG con fondo definido: No se vuelven invisibles contra fondos oscuros
